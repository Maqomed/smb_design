Overview
What is SMB ERP?

SMB ERP is a business management system designed specifically for small and medium-sized companies. It replaces a scattered collection of spreadsheets, paper records, and disconnected tools with a single, easy-to-use web application.

The system covers every core area of a business — from recording a sale or purchase, to tracking stock in the warehouse, to reconciling bank transactions and generating financial reports. Everything is connected, so information entered in one area is immediately reflected everywhere else.

The interface is available in three languages — Azerbaijani, English, and Russian — making it accessible to a broad range of users without any additional configuration.

Audience
Who is it for?

SMB ERP is built for businesses that have outgrown spreadsheets but do not need (or cannot afford) the complexity of large enterprise systems like SAP or Oracle.

Typical users include business owners who want a clear financial picture of their company, accountants managing invoices and payments, warehouse staff tracking stock movements, and sales teams creating and sending customer orders.

The system is designed so that different people can use different parts (modules) relevant to their role, all working from the same underlying data.

User Experience
How does a user interact with it?

The application follows a simple four-screen flow designed to feel intuitive from the first login.

SCREEN 01

Login

Users sign in with an email and password. The language of the interface is selected here and persists throughout the session.

SCREEN 02

Dashboard

A welcome screen listing all available modules. Users can search by keyword or filter to their most-used or recently visited modules.

SCREEN 03

Module View

Each module opens into its own workspace with a sidebar for sub-sections, a data table, and an action panel for creating and editing records.

SCREEN 04

Admin Profile

System administrators can view and manage their account settings, permissions, and system configuration from a dedicated profile page.

Key Qualities
What makes it stand out?

Everything in one place

No more jumping between separate apps. Finance, stock, sales, and banking share the same data in real time.

Multi-language support

The full interface is available in Azerbaijani, English, and Russian — switchable with a single click.

AZ EN RU

Clean, modern design

A professional visual identity that feels approachable — not intimidating like legacy ERP systems.

Role-based access

Each user sees only the modules relevant to their job. An accountant, a warehouse manager, and a salesperson each get a tailored experience.

Works on any device

The interface is fully responsive — it adapts gracefully to desktops, tablets, and mobile phones.

Designed for growth

Built modularly so new capabilities can be added as the business grows, without disrupting existing workflows.

Project Status
Where are we now?

The project is currently at the wireframe and design prototype stage. All four core screens have been built as interactive HTML wireframes that demonstrate the intended look, feel, and navigation of the system.

The wireframes are fully clickable — a user can log in with demo credentials, browse the module dashboard, navigate into a module's detail view, and visit the admin profile page. This allows stakeholders to experience the product's design and flow before any backend development begins.

The next step is to validate the design with end users, incorporate feedback, and begin the development of the live application.
